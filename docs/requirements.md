# Requirements Summary

Functional requirements implemented:

1. Create new document
2. Open existing document
3. Display with line numbers and pagination
4. Insert line / insert text inside line
5. Delete line / delete character range
6. Find (case-sensitive & insensitive)
7. Replace first / Replace all
8. Save / Save As with overwrite confirmation
9. Multi-level Undo
10. Multi-level Redo
11. Document statistics
12. Unsaved-change warnings
13. Robust input validation

Non-functional:

- C++17, standard library only for core logic
- Modular source layout
- Automated tests
- Clear documentation for viva and GitHub
